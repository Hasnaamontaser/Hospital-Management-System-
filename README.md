## Project Overview

The **Hospital Food & Maintenance Management System** is an integrated system designed to manage hospital food orders and maintenance requests efficiently.

The system allows patients to request meals and report maintenance problems, while the responsible hospital departments can manage, track, and update these requests through the system.

## Main Modules

### Food Ordering
- Patients can view available meals.
- Patients can place food orders.
- Food staff can view and manage orders.
- Order status can be updated:
  - Pending
  - Preparing
  - Ready
  - Delivered

### Maintenance Management
- Patients can report room or facility problems.
- Maintenance staff can view maintenance requests.
- Requests can be assigned and managed.
- Request status can be updated:
  - Pending
  - Assigned
  - In Progress
  - Completed

## User Roles
